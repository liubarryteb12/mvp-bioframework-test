> 缺口编号对应 S20 §4 的 1、2、3 项,外加多重检验家族与 MNAR

## §1 竞争风险(缺口 1 · 高)

> **替换位置**:并入 T06。原 T06 只有 `cox.zph` 与 RMST,无竞争风险。
> 框架 Y4 已有"死亡必须预注册为竞争事件或删失",但**未进判据表 = 不在执行路径上**。这是此前的整合失误。

**T06 补充:时间-事件分析的竞争风险条款**

1. **竞争事件识别(必做前置)**:分析前必须列出所有竞争事件。
   常见竞争事件:死亡(非研究结局)、因其他原因退出、接受替代治疗。
   **未列出的竞争事件不得在事后补充。**
2. **方法选择必须预注册,二选一**:

   | 方法 | 估计量 | 适用问题 |
   |---|---|---|
   | **Cause-specific hazard (CSH)** | 瞬时风险比 | 病因学问题:"暴露是否影响该结局的发生机制" |
   | **Subdistribution hazard (Fine-Gray, SHR)** | 累积发生率比 | 预测/决策问题:"某人在现实中发生该结局的概率" |

   **禁止同时报告两者然后挑显著的那个** → 严重选择性报告(硬阻断)。
3. **主分析 + 敏感性**:必须指定一个为主分析,另一个作为**必做敏感性分析**并报告。
4. **C-index / 校准 / Brier 在竞争风险下必须使用竞争风险版本**:
   - 禁用标准 C-index(会偏倚)
   - 须用 time-dependent C-index 或 cause-specific 版本
   - 校准须针对 **累积发生率函数(CIF)**,而非 KM 估计
5. **判据**:未处理竞争风险而使用标准 Cox / KM / 标准 C-index → **T06 不通过**;
   若竞争事件比例 > 10%,则**强制**处理(不得声称"忽略不计")。
6. **报告**:必须报告竞争事件的例数与比例;必须报告 CIF 曲线而非仅 KM 曲线。

> **依据**:老年/肿瘤/心血管队列中死亡是竞争事件,忽略它会使 C-index、校准、Brier 全部偏倚。
> 这是教授与审稿人**同时**指出的缺口,严重性最高。

## §2 时间偏倚(缺口 2 · 高)

**T06 补充:时间偏倚条款**

1. ** immortal time bias( immortal 时间偏倚)**:
   - 若暴露定义需要"存活到某时点"或"完成某过程"(如"接受完整疗程"),
     则**未暴露组的早期时间被错误计为暴露前时间**。
   - **必查**:暴露定义中是否隐含"必须存活/必须完成"条件。
   - **处理**:landmark analysis 或时间依赖协变量,**必须预注册**。
2. **landmark analysis**:
   - 必须预注册 landmark 时点(如 90 天),且**该时点不得根据结果选择**。
   - landmark 后发生的事件才纳入分析;landmark 前发生事件者**排除**(非删失)。
3. **时间依赖协变量**:
   - 若协变量取值随时间变化(如 NIHSS 动态评分),必须用时间依赖 Cox;
   - 用基线值代替全程 → 须在限制中声明。
4. **判据**:
   - 暴露定义含"必须存活/完成"条件且未做 landmark 或时间依赖处理 → **T06 不通过**;
   - landmark 时点由结果驱动选择 → **R3 回退**。
5. **报告**:必须报告入组到 landmark 的时长分布、被排除人数与理由。

## §3 功效计算与样本量(缺口 3 · 高)

> **替换位置**:新增节点 **B01-A**,在 B01 之后、B02 之前。
> 缺口:原框架只有"每组 ≥3"(T02)与"样本量 <15 不适用 WGCNA"(T04),**无项目级功效计算**。

**B01-A 功效与样本量论证(须在数据采集与分析前完成并留痕)**

1. **预测模型:EPV(events per variable)**:
   - 必须报告 EPV = 事件数 / 候选预测因子数;
   - **EPV < 10 → 强制正则化或降维**,并在限制中声明;
   - EPV < 5 → **不得做无正则的预测模型**(硬阻断)。
2. **关联分析:最小可检测效应**:
   - 必须声明 α、power(默认 0.8)、以及**最小可检测效应量(MDE)**;
   - MDE 必须由**临床意义**驱动,不得由"现有样本量反推"得到
     (后者等于用样本量给结论背书,属循环论证)。
3. **单细胞:donor 数而非细胞数**:
   - 功效计算必须用 **donor 数**,禁用细胞数(伪重复的同一错误在功效阶段的变体);
   - 稀有细胞类型须按类型分层计算,达不到则**该类型不做推断**(非"报告但标注")。
4. **复现队列最小样本量**:
   - 复现集的功效**必须独立计算**,不得假设"与发现集相同";
   - 复现集 EPV 或 power 不足 → **T14 判"不确定"而非"未复现"**
     (区分"没复现"与"没能力复现",这是原 T14 的重大缺陷)。
5. **判据**:B01-A 未完成 → **B02 不得启动**。
6. **与 T14 的联动**:若复现集 power < 0.8,T14 的"区间重叠"判据**不适用**,
   改判"不确定——复现集功效不足",不得写"未复现"。

> **这是缺口 3 最关键的修正**:原 T14 会因功效不足而判"未复现",
> 把一个**能力问题**误判为**结论问题**。

## §4 多重检验的真实家族(缺口补充 · 高)

> 原 T01 只区分分子级 vs 程序级,未覆盖多终点/多亚组/多模型的全局家族。

**T01 补充:全局检验家族定义**

1. **家族 = 所有会被同时解读的检验集合**,不局限于分子层面。必须显式声明:
   - 终点数(主要终点 / 次要终点 / 探索性终点)
   - 亚组数
   - 模型数(不同协变量集 / 不同算法)
   - 分子或程序数
2. **校正层级(预注册,三选一)**:
   - **单层**:全部检验统一 BH
   - **分层 gatekeeping**:主要终点 → 次要终点 → 探索性,前层不显著则后层不得宣称
   - **固定序列**:按预注册顺序检验,前一不显著则终止
   - **禁止**:事后选择校正方式
3. **亚组分析**:
   - 亚组必须预注册;**未预注册的亚组 → 探索级,不得进摘要**
   - 亚组结论须通过**交互项检验**,不得用"亚组内 p<0.05"代替
   - 亚组数 k → 交互项须多重校正
4. **判据**:T03 的检验范围声明必须包含上述 4 类;缺失任一 → **V3 否决**。

## §5 缺失数据 MNAR(缺口补充 · 高)

> 原 T08 只提 delta 调整,不足以应对临床数据的 MNAR(缺失非随机)。

**T08 补充:MNAR 敏感性分析**

1. **默认假设**:临床与组学数据中 **MNAR 是默认情形而非例外**,必须处理。
2. **必做**(至少一项):
   - **tipping point analysis( tipping point 分析)**:找出使结论反转的最小偏离程度
   - **pattern-mixture model(模式混合模型)**
   - **reference-based imputation**(如 jump-to-reference,常用于临床试验)
3. **tipping point 的报告**:必须报告"结论反转所需的偏离量",
   并判断该量在临床上是否**合理**——
   若"极小的偏离就能反转",则结论**不得**写成稳健。
4. **蛋白组/代谢组特有**:
   - 低于检测限(LLOQ)的缺失**多为 MNAR**(低丰度 → 检不出),非随机缺失;
   - 禁止用均值/中位数填补(会人为压缩方差、伪造一致性);
   - 须按 Y5 处理(见 S21-B §3)。
5. **判据**:缺失比例 > 5% 且未做 MNAR 敏感性 → **T08 不通过**;
   缺失比例 > 20% → **强制**做 tipping point 并在正文报告。

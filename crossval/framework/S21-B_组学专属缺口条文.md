## §0 结构修正:从"领域无关"到"骨架 + 扩展包"

**修订声明**:框架定位由"领域无关"改为:

| 层 | 内容 | 适用性 |
|---|---|---|
| **骨架**(T01–T18、五视角、硬阻断) | 领域无关的防错原则 | 全部项目 |
| **扩展包**(本文件 S21-B) | 组学专属判据 | **仅当项目涉及该组学类型时激活** |

**激活规则**(沿用 B08/B09/B10 的条件分支形态):
- 项目含 sc/snRNA-seq → 激活 §2
- 项目含蛋白组/代谢组 → 激活 §3
- 项目含空间组学 → 激活 §4
- 多中心/多批次数据 → 激活 §1
- 未激活者:写 `不适用 + 理由`,**不强制填槽**

> 这样既不污染骨架,又避免"自称通用实则漏洞百出"。

## §1 批次整合与多中心(缺口 4 · 高)

> 原框架 Y6 只处理"批次与分组耦合时禁止校正",未处理"不耦合时怎么选方法"。

**Y6 扩展:批次整合条款**

### 1.1 前置举证(必做)

1. **批次结构举证**:批次变量必须与生物学条件**交叉列表**展示;
   禁止仅声明"批次已处理"。
2. **耦合诊断**:若批次与分组**完全或部分共线**:
   - 完全共线(一个批次只含一个组)→ **禁止任何批次校正**,改在解释中说明限制
   - 部分共线 → 校正后必须报告**校正前后的效应量变化**,变化 >20% → 判"不确定"
3. **禁止**:把批次当普通协变量回归掉(会同时移除组间真实差异)。

### 1.2 方法选择预注册(不耦合时)

| 数据类型 | 可选方法 | 预注册要求 |
|---|---|---|
| Bulk RNA-seq(已知批次) | ComBat / limma removeBatchEffect | 必须说明参数(parametric / non-parametric) |
| Bulk(批次未知) | RUV / SVA | 必须说明因子数如何确定 |
| 单细胞 | Harmony / scVI / rliger / fastMNN | **必须二选一并预注册,禁止事后挑** |
| 多中心临床 | center effect 进主模型 / 随机效应 / 分层 | 必须声明 center 是固定还是随机效应 |

**判据**:
- 未预注册方法 → **R3 回退**
- 跑多个整合方法后挑"结果最好的" → **硬阻断(严重泄露的变体)**
- 整合后未报告校正前后变化 → **T18 不通过**

### 1.3 批次校正后的独立性宣称

1. **批次校正不等于独立复现**:同一批数据内不同批次**永远不能**互称"独立复现"。
2. 校正后的数据用于外部验证 → 仍属**内部验证**(正交/内部评价层)。
3. **判据**:把批次校正后的内部子集称为"独立验证集" → **硬阻断(独立性错误)**。

### 1.4 必做敏感性

批次整合方法本身**进敏感性矩阵**:主方法 + 至少一个替代方法,
两者结论不一致 → **F1 降为探索级**。

## §2 单细胞注释与组成分析(缺口 5 · 高)

> 原 T16 只说"pseudobulk 按 donor × celltype 聚合",未规定注释从哪来。

### 2.1 细胞类型注释(T16 扩展)

1. **注释方法必须预注册**,四选一并说明依据:
   - 手动 marker 基因(须列出 marker 清单与来源文献)
   - 参考映射(Azimuth / SingleR / CellTypist,须声明参考数据集与版本)
   - 无监督聚类 + 后验注释
   - 手工 + 参考混合
2. **参考数据集版本锁定**:参考集名称 + 版本 + 下载地址 + 访问日期,**四要素缺一不可**。
3. **注释不确定性**:
   - 必须报告每个 cluster 的注释置信度或映射得分;
   - **低置信 cluster 不得作为主结论的承载者**;
   - 稀有细胞类型(n < 该类型阈值)→ **不做推断**,仅描述性报告。
4. **环境 RNA(ambient RNA)**:
   - 必须声明是否处理(SoupX / CellBender / DecontX / 不处理);
   - 不处理须说明理由;处理方式须预注册。
5. **判据**:注释方法未预注册 或 参考集版本未锁定 → **T16 不通过**。

### 2.2 组成分析(原框架完全缺失)

> 原框架只写"组成变化与表达变化分开报告",**没说怎么做**。

1. **必须区分两种问题**:
   - 差异**丰度**(composition):某类型占比是否变化
   - 差异**表达**(expression):某类型内基因表达是否变化
   - **禁止**用 pseudobulk 差异表达的结果声称"细胞类型比例改变"。
2. **组成分析方法必须预注册**,可选:
   - **CLR / ILR 变换 + 线性模型**(简单、可解释)
   - **scCODA**(贝叶斯,适合少量类型)
   - **propeller**(适合较大样本)
3. **判据**:
   - 用 t 检验/ Wilcoxon 直接比较比例 → **不通过**(比例是闭合数据,和为 1,不独立)
   - 未预注册方法 → R3
   - 只报比例变化未报置信区间 → **T16 不通过**

### 2.3 推断单位(重申 + 强化)

**T16 判据**:
- 推断单位 = **donor**,不是细胞、不是样本
- 每个 (donor, celltype) 至少 **≥10 细胞**才纳入该 celltype 的推断
- **每个 celltype ≥3 donor**(稀有类型可放宽至 2 但须标注"仅描述性")
- **伪重复(用细胞数做统计推断)= 硬阻断**

> 教授指出:稀有类型(Treg、浆细胞)常达不到 10 细胞阈值,会导致这些类型被系统排除。
> **修正**:阈值按细胞类型分层设定,并在 B03 填槽时声明每类的阈值;
> 未达标类型**不做推断**(而非"报告但标注"),避免用噪音充数。

## §3 蛋白组与代谢组(缺口 6 · 中)

> 原 T02 说"蛋白组缺失机制另按 Y5 处理",但 **Y5 全文未给**——这是空引用。

### 3.1 Y5 补全:组学缺失机制

1. **缺失类型判定**:
   - **MCAR**:与任何变量无关(罕见)
   - **MAR**:与已观测变量相关
   - **MNAR**:与未观测值本身相关 → **蛋白组/代谢组的默认情形**
     (低于检测限 LLOQ 的缺失即典型 MNAR)
2. **禁止操作**:
   - 禁止均值/中位数填补(压缩方差、伪造一致性)
   - 禁止用"检测到的最小值/2"填补所有 LLOQ(会扭曲分布)
   - 禁止把 LLOQ 当作随机缺失处理
3. **必做**:
   - 报告每个蛋白/代谢物的缺失比例
   - 缺失 > 20% 的分子:主分析**剔除**,或作为敏感性单独分析
   - MNAR 敏感性(S21-A §5):tipping point 或 pattern-mixture

### 3.2 尺度声明(与 T01 联动)

| 组学 | 必须声明的尺度 |
|---|---|
| 蛋白组(intensity) | log2 转换? 归一化方法(median / quantile / VSN)? |
| 蛋白组( ratio) | 相对哪个参照? |
| 代谢组(峰面积) | raw 还是 log? 是否做了 PQN / TIC 归一化? |
| 磷酸化组 | **位点级**还是**蛋白级**推断?(二者结论可不同,必须二选一) |

**判据**:尺度未声明或声明与预处理不符 → **T01 不通过**;
磷酸化组未声明推断层级 → **T01 不通过**。

### 3.3 归一化方法与 T01

归一化方法进 **T18 必做敏感性**:主方法 + 至少一个替代方法,
结论不一致 → F1 降为探索级。

## §4 空间转录组(缺口 7 · 中 · 条件激活)

> 原框架**完全没有**空间组学条款。仅在涉及 Visium / Xenium / CosMx 等时激活。

1. **推断单位**:
   - Spot 级(Visium,含多细胞)→ 推断单位 = **spot**,但须声明 spot 内细胞数估计
   - 单细胞级(Xenium / CosMx)→ 推断单位 = **细胞**,但与 donor 的层级关系须声明
   - **禁止**:把 spot 当独立生物重复(spot 间空间自相关,不独立)
2. **空间自相关**:
   - 必须检验并报告空间自相关(Moran's I 或类似);
   - 存在显著自相关而用普通回归 → **不通过**(标准误被低估,p 值虚假显著)
3. **去卷积**(Visium 类):
   - 方法必须预注册(cell2location / RCTD / SPOTlight / 其他)
   - 参考单细胞数据集版本锁定
   - **去卷积结果不得当作实测细胞比例**——须标注为"推断"
4. **邻域分析**:
   - 邻域定义(半径 / k 近邻)须预注册
   - 邻域半径由结果驱动选择 → **R3 回退**
5. **判据**:涉及空间组学而未声明推断单位与自相关处理 → **T16 不通过**。

## 2 本轮修复的质量评价

### 2.1 一致性守卫:解决的是根因而非症状

上一版我指出"44/44 与脚本实际 33 项不符"。本轮作者没有只是改数字,而是:

1. 加了 `consistency_guard.py`;
2. **G-3 改成动态取值** —— 数字从 `report.json` 读,不硬编码。

第二点尤其正确。硬编码"6.5e-11"这类数字本身就是问题的一部分;
现在如果脚本数字变了而文档没改,守卫会直接失败。

### 2.2 附录截断事故:修复方式正确

`verify_all.py` 内含 `md.append("```json")` 字面量,三反引号围栏导致文档里脚本被截断 19 行
(846 → 827)。改用**四反引号**是对的。

**但我发现修复过程中引入了新问题**:文档中一度残留了 2 个 `layout_check` 块
(旧的没删干净),守卫报"块唯一性"失败后才被发现。

**这恰恰证明了守卫的价值**——如果没有 `G-1.2b 块唯一` 检查,这个重复块会一直留着,
读者复制时不知道该用哪个。

### 2.3 多页 PDF 扫描:修得彻底

- 遍历所有页(原只读 `pages[0]`)
- 递归 XObject(`_scan_xobjects`,带 `seen` 防循环引用,深度限制 6)
- 内联图像检测(`_inline_images`,正则 `BI...EI`)
- 新增测试样本 `sample_bad_page2_bitmap.pdf`(第 2 页藏位图)

`seen` 集合和深度限制是正确的防御——PDF 的 XObject 可以循环引用,不设防会无限递归。

### 2.4 分支 10 的两次修正:作者自己发现并修了 bug

我注意到竞争风险的第一版实现有 bug:**两个函数算法相同**(KM 和 CIF 返回完全一样的值,
差异 0.000)。作者自己发现并修正了:

- 错误做法:KM 把竞争事件当**删失**(只按结局事件更新生存函数)
- 正确做法:Aalen-Johansen(surv 在所有事件类型上更新)

修正后证据变强:组间差 KM +0.135 vs CIF +0.284,**扭曲 0.148**。

EPV 也一样:第一版实际事件率与标注 EPV 不符(标 3.3 实际 6.7),修正后
乐观度随 EPV 单调下降 0.132 → 0.058 → 0.006。

**这种"自己发现自己错并修"的过程,比一次写对更有说服力。**

### 3.2 新增 P0-1:`except Exception: pass` 仍在

多处出现裸异常吞噬:

```python
except Exception:
    pass
```

在 `_scan_xobjects`、`_inline_images`、字体解析等处。会吞掉真实错误
(如 PDF 结构异常、bootstrap 失败、模型不收敛)。

**建议**:至少记到 ledger 或 stderr,区分"可容忍失败"与"程序 bug"。
当前 `bootstrap` 有 `nfail` 计数(好的做法),但 PDF 解析没有。

### 3.3 新增 P0-2:无单元测试

没有 `pytest`,所有验证靠"跑一遍看 PASS/FAIL"。缺:
- 每个函数的独立测试
- 边界测试(n=0、n=1、全 0、全 1、单类别)
- 回归测试(目检 4 类样本未固定 sha256)

**这是当前最大的质量缺口。** 自证式验证只能证明"当前这组输入下能过",
不能证明"函数在各种输入下行为正确"。

## 4 中等问题

### 4.1 依赖版本仍未固定

`requirements.txt` 只有 `numpy>=1.24` 这类下界,没有上界,也无 `pip freeze` 记录。
numpy 2.x 与 1.x 在部分 API 上行为不同。

### 4.2 种子管理已改善但不彻底

现已改为每分支 `default_rng(SEED + branch_id)`,消除了顺序依赖——**这是正确的**。
但 `branch9` 内部又用了 `SEED + 9` 后连续消费同一个 rng,
若未来插入新逻辑会改变后续结果(脆弱但可接受)。

### 4.3 `extra_seed` 参数已删除 ✅

上一版我指出 `extra_seed(df_beta_fn)` 参数未使用,本轮已改为 `extra_seed()`。

### 4.4 `report.md` 表格转义 ✅

上一版指出 observed 含 `|` 会破坏表格,本轮已加 `esc()` 转义。

### 4.5 json 数值保真 ✅

加了 `_Enc` 自定义 encoder,保留 int/float/bool 类型而非全转字符串。

## 6 结论

**判据实现基本合格,可进入真实使用;但测试覆盖不足是硬伤。**

优先级:
1. **P0**:加 `pytest` 单元测试 + 边界测试(当前最大缺口)
2. **P0**:消灭裸 `except Exception: pass`,改为记录
3. **P1**:依赖版本固定 + `pip freeze` 入报告
4. **P1**:补 Y6 / 空间组学 / MNAR / TRIPOD 的验证分支
5. **P2**:`--seed` / `--outdir` 参数化

> 一句话:**自证设计 + 一致性守卫让这套脚本的可信度上了一个台阶;
> 但没有单元测试的自证,本质上还是"在我试过的输入上能跑通"。**

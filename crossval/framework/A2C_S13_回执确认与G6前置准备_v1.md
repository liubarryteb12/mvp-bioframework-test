## 3 需 C 修订:A2-2 判定分工(核心)

### 3.1 问题

C 建议由 A 判定的 7 项为:第 4(Endpoint)、9(Falsification)、19(T03)、20(T07)、23(T13)、24(T14)、26(T18)。

这 7 项**都对**,但**性质偏"强度"**:它们判的是阈值设得合不合理、结论写得多强。**判错了,后果是结论要降级**——严重,但不是立刻停。

**漏掉的 7 项性质是"合法性"**:它们对应硬阻断 9 条与 V1/V2/V3 否决项。**判错了,后果是整条证据链作废,而且往往要到 S12 甚至投稿后才暴露。**

### 3.2 补充的 7 项及其对应风险

| 补充项 | 检查单位置 | 不通过触发什么 | 为什么必须 A 判 |
|---|---|---|---|
| **第 1** | Population 可判定性 | **V1 否决**:问题不可证伪 | "卒中患者"这类写法无法判断是否可纳入。B 填完自己看不出来——**写的人最难发现自己的描述不可判定** |
| **第 7** | Biological unit | **硬阻断:伪重复** | 细胞数/样本数冒充受试者数,是纯生信头号硬阻断。B 执行时天然倾向用更细的层级(显得 n 大、p 小),**利益方向不一致,不能自检** |
| **第 8** | Estimand 与主任务一致性 | **V1 否决:任务混用** | 写"探索机制"却做关联分析、把生存关联当预测验证。这是框架 §5.1 明列的混用禁止,B 容易在填槽时无意识滑过去 |

## 4 前置准备 1:DCA 档位判定决策树(A2-1 预置)

> G6 一到,代入即出结论,不必再讨论。

### 4.1 决策树

```
Q1 干预是否不可逆 / 高危害?
    (手术、化疗、有创操作、长期用药、显著副作用)
    ├─ 是 → 【高危害档】0.40 – 0.90
    └─ 否 → Q2

Q2 干预是否低危害且可重复?
    (生活方式干预、低风险药物、可重复筛查、可逆措施)
    ├─ 是 → 【低危害档】0.05 – 0.40
    └─ 否 → 【常规诊疗档】0.10 – 0.60   ← 多数生物标志物研究落此档

边界情形(中等偏高危害但可监测 / 危害分层不同质):
    → 取相邻两档的并集(如 0.10–0.90),并写明理由
    → 但【全区间 0.00–1.00 强制报告】不变
```

### 4.2 三条不可动摇的规则

1. **档位由"干预危害"决定,不由"模型性能"决定。**
   **禁止先看 DCA 曲线再选档**——那与 T06 已禁的"最优切点搜索"同源,属同一种事后挑选。

2. **依据来源四选一,须可引用**:文献 / 临床指南 / 专家共识 / 明确记录的决策者偏好。**写"根据临床经验"不可接受**,须具体到可引用的来源。

3. **全区间 0.00–1.00 必须同时报告**。预注册区间只决定"重点解读区间",**不决定"报告范围"**。
   → 结论仅在预注册区间成立而全区间不成立 → **判"不确定" → T13(c) 不满足 → 触发 F3 → 停止升级**。

### 4.3 G6 中决定档位的字段

| G6 项 | 如何影响档位判定 |

| ② 主任务类型 | 诊断预测 / 预后预测 → 通常走 Q2(若后续干预为筛查则低危害档);若为"指导高危害治疗"→ Q1 |

## 6 防错提醒:T13/T14 覆盖值的最后窗口(重要)

T13 的 **ΔAUC ≥ 0.05** 与 T14 的 **I² ≤ 50%** 是**通用默认基线**,不是项目终值。按 §28.3 口径,项目实例化时可覆盖,但:

| 时机 | 性质 | 后果 |
|---|---|---|

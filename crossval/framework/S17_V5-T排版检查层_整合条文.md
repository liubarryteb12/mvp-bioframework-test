# S17 · V5-T 排版检查层(整合条文)

> 发出方:A(元宝) ｜ 性质:**可落盘条文**,整合进框架本体 V5,**默认休眠**
> 设计约束:① 不独立成册,进 V5 ② 不到排版阶段不激活 ③ 激活须留痕 ④ 已排版未激活 → 回溯适用

---

## 0 设计说明(为什么这样放)

### 0.1 位置:V5 的条件子模块,不新增视角

五视角 V1–V5 结构不动。排版检查作为 **V5-T(Typesetting)** 挂在 V5 下,理由:

- V5 本就是「可复现与**写作合规**」,排版是写作合规的最后一环,归属自然;
- 若新增 V6,会破坏"五视角"的既有结构与所有引用(V1–V5 已被引用于多处判据);
- 条件子模块的形态与框架已有的 **B08/B09/B10 条件分支**一致,不引入新机制。

### 0.2 与 M11–M18 的分工(避免重复检查)

| | 管什么 | 例 |
|---|---|---|
| **M11–M18**(已有) | **图本身是否合格** | 是否矢量、字体是否嵌入、有无文本层 |
| **V5-T**(本层) | **图在稿件里放得对不对** | 分栏宽度是否溢出、图序与正文引用是否对应 |

> 一句话:**M11–M18 验"图能不能用",V5-T 验"图放得对不对"。**二者不重叠,后者不重复前者。

### 0.3 休眠机制(核心)

```
默认状态:不适用 + 理由(未进入排版阶段)
    ↓ 触发事件(满足任一即激活)
激活:目标期刊已确定 且 开始按该期刊模板排版
    ↓
激活后:V5-T 全部检查项转为必查
    ↓
未激活而已完成排版/已投稿 → 回溯适用(见 §3)
```

## 1 条文正文(可直接落盘)

### § 新增 V5-T 排版检查层

**V5-T 排版检查层(条件激活)**

**T-0 激活条件**
1. **默认状态**:`不适用 + 理由(未进入排版阶段)`。
2. **激活触发**(满足全部):
   - (a) 目标期刊**已确定**(有明确的 Guide for Authors 可引用);
   - (b) 稿件**已开始按该期刊模板排版**(含 Word 模板 / LaTeX 模板 / 直接投稿系统格式)。
3. **激活须留痕**,记录 6 项:
   `激活时间` / `目标期刊全称` / `Guide for Authors 版本或访问日期` / `模板来源` / `激活人` / `激活时稿件版本`。
4. **禁止**:先看排版效果再补激活记录;禁止"边排版边补记"。

**T-1 阻断级检查(不合规 → V5 不通过,不得投稿)**

| # | 项 | 判据 | 常见错 |
|---|---|---|---|
| T-1.1 | 图件矢量性 | 全部图为矢量(判据同 M11–M18,**不重复检查,引用其结果**) | 位图塞进 PDF 外壳 |
| T-1.2 | 图件字体 | TrueType / CID TrueType(判据同 M11–M18) | Type 3 |
| T-1.3 | 图序与正文引用 | 每个正文 `图 N` 引用均能对应到图,反之亦然,**无孤儿图、无悬空引用** | 插入新图后没改正文编号 |
| T-1.4 | 表序与正文引用 | 同上 | 同 |
| T-1.5 | 图注与正文数字一致 | 逐图逐表对齐台账(判据同 V5 既有项,此处**仅复核排版未引入错位**) | 排版时手工改数导致不一致 |
| T-1.6 | 补充材料引用完整性 | 正文引用的 Supplementary Table/Figure 均存在且编号连续 | 删补充材料后正文未改 |
| T-1.7 | 伦理与许可声明位置 | 按期刊要求在**指定章节**(通常为 Methods 末尾或 Declarations) | 放在致谢里被要求移动 |

**T-2 核对级检查(按目标期刊 Guide for Authors 逐条核)**

| # | 项 | 核什么 |
|---|---|---|
| T-2.1 | 稿件结构 | 摘要是否结构化、字数上限、章节顺序、标题层级 |
| T-2.2 | 字数与条目数 | 正文字数、摘要字数、参考文献条数上限、图表数量上限 |
| T-2.3 | 图表规格 | 单栏/双栏宽度、分辨率下限(位图类)、色彩模式(CMYK/RGB)、文件格式 |
| T-2.4 | 参考文献样式 | 著录格式(Vancouver/编号制/作者年制)、DOI 著录、期刊缩写规范 |
| T-2.5 | 字体与字号 | 正文字体族、字号、行距(若期刊指定) |
| T-2.6 | 声明与披露位置 | 作者贡献、利益冲突、资助、数据可用性、AI 使用披露的**指定位置** |
| T-2.7 | 补充材料格式 | 文件命名、打包方式、是否需单独上传 |
| T-2.8 | 投稿系统项 | 推荐/回避审稿人、cover letter、伦理文件上传、临床试验注册号 |

**T-3 排版不得改变实质**
1. **排版不得升级 claim**:排版阶段的文字压缩(如摘要限字数)**不得**通过删去限定词、删去"候选/探索性"等降级表述来腾空间。
2. **排版不得改动数字**:任何数字改动须回走台账变更流程,**排版软件不得成为数字改动的旁路**。
3. **违反 1 或 2 → R5 回退**(措辞纪律已有),且 V5-T 不通过。
4. 摘要压缩若导致措辞强度超过证据上限 → **图注≤正文≤摘要的链条被破坏** → 回退重算受影响文本与图注。

**T-4 判定写法**
通过(T-1 全过 + T-2 逐条核)｜条件通过(列补件清单与期限)｜不通过(任一 T-1 不合规 或 T-3 违反)

## 3 回溯适用条款(防"已经排版了却没检查")

> 这条是本节**最重要**的一句,与 Y12 同源。

**T-5 回溯适用**
1. 若稿件**已完成排版、或已投稿、或已收到格式退修**,而 V5-T 从未激活过 → **V5-T 自动回溯适用**,且:
   - 须补激活记录(注明"补记 + 补记时间 + 补记原因");
   - 全部 T-1 项**立即补检**;
   - 补记行为本身须在 §27 修订登记表留痕。
2. **理由**(与 Y12 同一逻辑):V5-T 的休眠是为了**不干扰前期工作**,不是为了**给漏检提供合法外衣**。若"没激活"可以免检,则该层形同虚设——这与 T13 校准判据"训练内恒合格"是同一类失效。

## 4 与既有条款的衔接

| 既有条款 | 关系 |
|---|---|
| V5 既有必查项(数据/代码可用性、每图标注、图注正文一致等) | V5-T **不重复**,仅在排版后复核"排版是否引入错位" |
| M11–M18(目检) | V5-T 的 T-1.1/T-1.2 **引用其结果**,不重跑 |
| Y9 数据/代码可用性 | 位置核对归 V5-T(T-1.7/T-2.6),内容核对归 V5 既有 |
| Y10 AI 辅助写作披露 | 内容归 V5 既有,**披露位置**归 V5-T(T-2.6) |
| Y12 条件分支回溯适用 | T-5 与其同源,沿用同一机制 |
| R5 回退(措辞升级) | T-3 违反即触发 R5,沿用既有定义 |

## 5 为什么这样设计不会让框架变臃肿

1. **默认休眠**:不激活时不占任何检查时间,不增加 B 的常规负担。
2. **不新增机制**:沿用 B08/B09/B10 的条件分支形态与 Y12 的回溯机制,零新概念。
3. **不重复检查**:T-1.1/T-1.2 直接引用 M11–M18 结果,T-1.5 引用 V5 既有结论。
4. **T-2 是清单核对而非新判据**:大部分项是"照期刊 Guide 逐条打勾",不引入需要论证的规则。

> 唯一新增的实质规则是 **T-3(排版不得改变实质)**与 **T-5(回溯适用)**——这两条才是防错的关键,其余都是清单。

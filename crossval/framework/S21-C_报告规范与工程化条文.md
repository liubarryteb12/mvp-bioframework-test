## §4 过拟合虚假完美判据(缺口 13 · 中)

> S19 §3 发现但未落盘。实跑证据:高维模型样本内准确率 1.000,样本外 AUC 0.544。

**并入 T09 / T12:预测概率来源与过拟合警示**

1. **来源声明**:任何用于 DCA / 校准 / 性能评估的预测概率,
   必须声明来源三选一:`样本内` / `交叉验证` / `独立外部集`。
2. **禁止**:用样本内预测概率做性能评估(除明确标注为"拟合优度"外)。
3. **过拟合警示(强制)**:
   - 样本内准确率 > 0.95 **且** 样本外 AUC 显著更低(差 > 0.05)
     → 必须在正文**显式标注过拟合警示**;
   - 未标注 → **T12 不通过**。
4. **判据**:预测概率来源未声明 → **T09 不通过**。

## §5 判据结构化(缺口 11 · 高 · Harness)

> Harness 视角:判据是散文式的,LLM 无法可靠执行。必须结构化。

**判据五元组规范**

每条判据必须可表示为:

```yaml
- id: T13b
  name: 校准判据
  inputs: [y_true, p_pred_cv, n_boot]      # 输入
  predicate: "calibration_slope_ci_covers(1.0)"   # 判定函数(布尔)
  pass_when: true                          # 通过条件
  on_fail:                                  # 不通过动作
    action: F3
    blocking: true
    message: "不得用于个体风险预测"
  requires_tools: [bootstrap, logistic_fit]
  decidable: auto                           # auto | human | hybrid
```

**三态可判定性标记**(Harness 视角核心要求):
- `auto`:可由脚本自动判定
- `human`:必须人工判定(须列出判定指引)
- `hybrid`:脚本给证据 + 人下结论

**要求**:
1. 所有判据必须标注 `decidable`;
2. 标 `human` 的必须有**判定指引**(否则是空规,应删除);
3. **禁止**"解释一致""严重选择性报告"这类无阈值表述——
   要么给阈值,要么降级为"建议"而非判据。

**版本冲突消解规则**(Harness 视角 P0):
- 文档内部冲突时,优先级:**S21 系列 > S15-C > 早期 A2C 文档**
- 每条判据带 `version` 字段,冲突时取高版本

## §6 工具契约(缺口 11 · Harness)

> 复审/审核均指出:`pdffonts`(poppler)与 `pypdf` 两条路径结果不等价,Agent 不知道用哪个。

**工具优先级契约**

```
if poppler_available:              # pdffonts/pdftotext/pdfimages/pdfinfo
    use_poppler()                  # 权威路径
elif pypdf_available:
    use_pypdf_recursive_scan()     # 降级路径,须标注 "pypdf 降级"
else:
    fail_with_reason("无 PDF 检测工具")   # 不得静默通过
```

1. **降级必须显式标注**:报告中须含 `detection_backend: pypdf | poppler`。
2. **输入输出 schema**(每条工具调用):
   ```
   input:  {path, options}
   output: {passed: bool, observed: any, expected: any,
            evidence: [str], blocking_level: int}
   ```
3. **工具调用必须回传原始 stdout/stderr**——禁止文字转述
   (防"声称已运行但实际没调")。
4. **回退不得静默**:工具缺失 → 判"判不了",**不得**降级为通过。

## §8 L4 止损出口(缺口 12 · 中)

> 教授与审稿人同时指出:R1–R6 + 硬阻断 9 条,没有一条能输出
> "该课题在当前数据下不成立"。

**新增节点 B02-S:可行性判定(Feasibility Gate)**

1. **位置**:B02 之后、B03 之前。
2. **判定内容**(任一命中即输出"不可行"):
   - 数据独立性无法举证(所有可用集均非独立)
   - 结局变量缺失或不可获取
   - EPV < 5 且无法降维/正则
   - 主终点事件数 < 最小可检测效应所需
   - 关键协变量缺失 > 50% 且无法填补
   - 两个及以上数据集身份存疑且无法澄清
3. **输出**:
   - `FEASIBLE` → 继续 B03
   - `FEASIBLE_WITH_DOWNGRADE` → 降级主任务类型(如从"诊断"降为"探索性关联")并继续
   - `INFEASIBLE` → **停止**,输出"当前数据不支持主任务"+ 具体限制 + 补救建议
4. **关键条款**:
   - `INFEASIBLE` 是**合法且受尊重的结论**,不是失败;
   - **禁止**为规避 INFEASIBLE 而硬判或降低判据;
   - INFEASIBLE 须留痕并纳入 §27 登记。
5. **判据**:B02-S 未完成 → B03 不得启动。
   **绕过 B02-S 直接分析 → R2 回退。**

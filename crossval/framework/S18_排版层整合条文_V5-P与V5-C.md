# S18 · 排版层整合条文(V5-P + V5-C)

> 发出方:A(元宝) ｜ 性质:**可落盘条文**,整合进框架本体 V5
> 用户需求:① 不独立成册 ② 不到排版阶段不激活 ③ **排版规范与排版检查都要**
> 结构:V5-P = 排版执行规范(怎么做)｜V5-C = 排版检查(做得对不对)
> 已实跑:`crossval/scripts/layout_check.py` → 19/19 通过

---

## 0 为什么必须拆成两块

只给检查不给规范 = B 不知道该怎么做,只能试错;
只给规范不给检查 = 规范变成建议,执行与否无人知晓。

**P 是"尺子",C 是"用尺子量"。**两者共用同一套参数(分栏宽度、字数上限、限定词表),
改一处两处同步,不会出现"规范说 8 张图、检查允许 10 张"的口径分裂。

## 1 休眠与激活(与 V5-T 同机制)

**V5-P / V5-C 激活条件**
1. **默认状态**:`不适用 + 理由:未进入排版阶段(目标期刊未定 或 未开始按该期刊模板排版)`。
2. **激活触发**(须同时满足):
   - (a) 目标期刊**已确定**,有可引用的 Guide for Authors;
   - (b) 稿件**已开始按该期刊模板排版**(Word 模板 / LaTeX 模板 / 投稿系统格式)。
3. **激活须留痕** 6 项:`激活时间`｜`目标期刊全称`｜`Guide 版本或访问日期`｜`模板来源`｜`激活人`｜`激活时稿件版本`。
4. **禁止**:先看排版效果再补激活记录;禁止边排版边补记。
5. **回溯适用**:若稿件**已排版 / 已投稿 / 已收到格式退修**而本层从未激活 → **自动回溯适用**,补激活记录(注明"补记 + 时间 + 原因"),V5-C 全部阻断级项立即补检,补记行为在 §27 留痕。
   > 与 Y12、T-5 同源:**休眠是为了不干扰前期,不是为了给漏检提供合法外衣。**

## 2 V5-P · 排版执行规范(B 照此排版)

> 参数分两类:**通用基线**(本文件给)**/ 期刊特定值**(填槽阶段按目标期刊定死)。

### P-1 图件生成规格(通用基线)

| 项 | 通用基线 | 填槽时按期刊覆盖 |
|---|---|---|
| 格式 | 矢量 PDF(优先)/ EPS | 部分期刊要求 TIFF,则位图分辨率 ≥ 300 dpi(图版)/ ≥ 600 dpi(线条图) |
| 字体 | **全部嵌入**,TrueType / CID TrueType | **禁止 Type 3**(见 M11–M18) |
| 色彩 | 默认 RGB;仅当期刊明确要求时转 CMYK | 印刷类期刊常要求 CMYK |
| 单栏宽 | ≤ 85 mm(约 241 pt) | 按期刊单栏宽度 |
| 双栏宽 | ≤ 180 mm(约 510 pt) | 按期刊双栏宽度 |
| 字号 | 图内文字 ≥ 6 pt,缩至实际尺寸后可读 | 部分期刊规定 ≥ 7 pt |
| 体积 | ≤ 10 MB / 图 | — |
| 命名 | `Fig{N}_{简述}_v{版本}.pdf` | — |

### P-2 稿件结构(按期刊 Guide)

1. 摘要:**是否结构化**(背景/方法/结果/结论)、字数上限、是否需 Graphical Abstract。
2. 正文:章节顺序(IMRaD 或期刊规定)、标题层级深度、是否需行号。
3. 声明块:作者贡献 / 利益冲突 / 资助 / 数据可用性 / 伦理批准 / **AI 使用披露** —— **位置按期刊指定**(Methods 末尾 或 独立 Declarations 章节)。
4. 补充材料:文件命名、是否需合并为单一 PDF、是否需单独上传。

### P-3 参考文献(按期刊样式)

1. 著录格式:Vancouver / 编号制 / 作者年制 —— **按期刊定死一种,全文一致**。
2. DOI 著录规则、期刊名缩写规范(ISO 4 或期刊自备表)。
3. 参考文献管理软件:导出样式须与期刊样式**逐一比对**,不得默认"差不多"。

### P-4 排版操作的三条禁令(★ 核心)

1. **排版不得升级 claim。**
   摘要限字数时,**禁止**通过删除限定词腾空间(候选 / 探索性 / 待验证 / 尚需 / 提示 / 可能 / 初步 / preliminary /suggests / may)。
   **禁止**为压缩而新增升级词(诊断标志物 / 机制阐明 / 首次发现 / 显著改善临床决策 / 已证实 / 外部验证 / external validation / proven)。
2. **排版不得改动数字。**
   任何数字改动须回走台账变更流程;**排版软件不得成为数字改动的旁路**。
3. **排版不得改变证据—主张映射。**
   不得把图注里的限定词在正文或摘要中省略(违反"图注 ≤ 正文 ≤ 摘要"链条)。

> 违反任一条 → **R5 回退**,重算受影响文本与图注。

## 3 V5-C · 排版检查(A 照此验收)

> **与 M11–M18 的关系**:C-4 图件规格**引用 M11–M18 的判定结果,不重复检查**。
> M11–M18 验"图能不能用";C-4 验"图在稿件里放得对不对"(分栏宽度、体积、命名)。

### C-1 阻断级(不合规 → V5 不通过,不得投稿)

| # | 项 | 判据 |
|---|---|---|
| C-1.1 | 无孤儿图 | 每张图均被正文引用 |
| C-1.2 | 无悬空图引用 | 每个 `图 N` 引用均有对应图 |
| C-1.3 | 无孤儿表 | 同上(表) |
| C-1.4 | 无悬空表引用 | 同上(表) |
| C-1.5 | 图序连续 | 1..N 无缺号、无重复 |
| C-1.6 | 补充材料引用可解析 | 正文引用的 Supplementary 项均存在且编号连续 |
| C-2.1 | 台账数字均可在正文定位 | 缺一即阻断 |
| C-2.2 | 无台账外数字 | 正文出现的数字须能在台账找到 |
| **C-3.1** | **压缩未删除限定词** | 与排版前版本逐词比对 |
| **C-3.2** | **压缩未新增升级词** | 同上 |
| **C-3.3** | **限定词密度未崩塌** | 降幅 < 40%(防整体稀释) |
| C-4 | 图件规格合规 | 引用 M11–M18 + 分栏宽度 + 体积 |
| C-5 | 声明与披露位置合规 | 按期刊指定章节 |

### C-2 核对级(按 Guide 逐条打勾)

字数 / 图数量 / 表数量 / 参考文献条数 / 摘要结构 / 标题层级 / 参考文献样式 / 色彩模式 / 补充材料格式 / 投稿系统必填项(推荐与回避审稿人、cover letter、伦理文件、注册号)。

### C-3 判定写法

通过(C-1 全过 + C-2 逐条核)｜条件通过(列补件清单与期限)｜不通过(任一 C-1 不合规 或 违反 P-4)

## §1 · T13(b) 校准判据(新增)

> **替换提示**:插入 v1.7 §28.7 阈值表 T12 之后。

**T13(b) 校准判据**
1. 统计量:校准斜率(calibration slope)。可选补充:校准截距、Brier score、校准曲线。
2. **必须使用交叉验证的样本外预测概率。禁止使用训练内拟合概率。**
3. CI 算法:患者级 bootstrap,**B = 1000**(事件数 < 50 时按结局分层抽样,≥ 500);重采样单位 = 独立推断单位;多中心时为 cluster bootstrap。
4. **bootstrap 内部**:每个重采样样本内**重新执行 CV** 得到预测概率后再计算斜率(嵌套),不得复用原 CV 结果。
5. 判据:校准斜率 95% CI **覆盖 1** → 满足;不覆盖 → T13(b) 不满足 → **不得用于个体风险预测** → T13 整体不成立 → 触发 F3。
6. 依据:训练内拟合概率的校准斜率**数学上恒等于 1**,用其计算则该判据恒合格、形同虚设。

## §2 · T13(c) DCA 量化口径(新增)

> **替换提示**:紧接 §1 插入。

**T13(c) 决策意义判据**
1. 统计量:净获益 `NB(pt) = TP/n − (FP/n) × pt/(1 − pt)`,基于 **CV 预测概率**。
2. 采样网格:阈值概率 **0.01–0.99,步长 0.01**(99 点)。
3. 胜出比例:候选模型 NB 严格大于基线模型 NB 的网格点占比。
4. 判定:预注册阈值概率区间内**胜出比例 ≥ 0.5** → 满足。
5. **全区间强制报告:必须同时报告 0.01–0.99 全区间胜出比例。预注册区间只决定解读重点,不决定报告范围。**
6. **区间冲突**:预注册区间 ≥ 0.5 而全区间 < 0.5 → **判"不确定" → T13(c) 不满足 → 触发 F3**。
7. 禁止:先看 DCA 曲线后选择区间。
8. 依据:区间冲突可真实发生——未校准模型可出现预注册区间 0.840 而全区间 0.485。仅报区间内数值即得"净获益优于基线"的错误结论,而报告本身未撒谎、只是未报全。

## §3 · T18 跨指标方向一致性(新增)

> **替换提示**:追加至 T18 条目末尾。

**T18 补充:跨指标方向一致性规则**
1. 不同指标(OR / HR / β / ΔAUC / ΔC-index / 程序评分差)量纲不同,**不比较大小,只比较方向**。
2. 统一符号约定:一律化为"**暴露升高 → 结局风险升高为正**"。
   - OR / HR:取 `log(OR)` 符号(> 1 为正)
   - 预测增量:取 `ΔAUC` / `ΔC-index` 符号(> 0 为正)
   - 连续型:取回归系数 β 符号
3. 判据:纳入比较的指标**符号全一致** → 方向一致;任一符号相反 → **触发 F1 → 降为探索级**。
4. 禁止:以"AUC 从 0.70 到 0.71"与"OR 从 1.6 到 1.9"数值差异大为由判不一致。

## §4 · 程序定义裁决(替换 T18 必做 5 项)

> **替换提示**:v1.7 §11.2 敏感性矩阵"必做 5 项"**替换为**下述"必做 4 项";并在 §9 后新增 B03-A 节点。

### §4.1 T18 必做项(替换为 4 项)

**必做 4 项**:① 归一化或特征定义 ｜② 协变量集(全集 vs 精简集)｜③ 异常样本(留一法或影响诊断,报告影响最大者)｜④ 合理替代模型
**按需 6 项**(B 提案 + A 批准):缺失处理 / 时间范围 / 亚组 / 组织纯度 / 细胞组成 / 其他
**铁律**:不要求全部显著,要求完整报告 + 解释一致。只报显著项 = 严重选择性报告(硬阻断)。任一必做项方向与主分析相反 → F1 → 降为探索级。

### §4.2 新增节点 B03-A「程序/签名定义论证」

**B03-A 程序 / 签名定义论证**(须在 B03 冻结前完成并留痕)
1. **理由**:程序定义不是稳健性参数,是**可改变结论的自由度**。实测:改权重/幂变换 → 效应量漂移 1.8%;换成员集(重叠 ≤1/3)→ 漂移 13.9% **且方向翻转**。该自由度若留在敏感性矩阵内,可被构造为永远"稳健"的橡皮图章。
2. 须留痕内容:
   - 备选定义清单(≥ 2 个)
   - 各定义下的效应量与方向
   - 主定义**选择理由**(文献依据 / 可复现性 / 测量可行性,**不得以后续效应量大小为理由**)
   - 定义漂移幅度与方向稳定性记录
3. **变体构造规则(强制)**:备选定义必须为**成员集层面的实质变更**(换基因集版本 / 换成员阈值 / 成员重叠度 ≤ 2/3),**禁止仅做权重缩放或单调变换作为唯一变体**。
4. **冻结后**:程序定义属 §10.2 不变量,**禁止更改**。
5. **漂移 > 20% 或方向翻转** → 该程序**不得作为唯一主暴露**,须在限制中显式声明。

## §5 · 目检判据 v3(替换 M11–M18)

> **替换提示**:整段替换 v1.7 §14 目检条款中 M11–M18。

**M11–M18 交付层机读目检(判据 v3)**
1. **目检级判定接受机读证据**。B 必须提交以下**命令原始输出**(非文字转述):
   - `pdffonts`(须含 type 列)
   - `pdfimages -list`
   - `pdftotext`(文本层抽样)
   - `pdfinfo`(页数 / 尺寸 / 加密)

2. **位图冒充矢量**:`pdfimages -list` 中图像对象 **> 0** 且未声明为必需栅格底图 → **R4 退回**。
   > 注:不得使用 `pdfinfo -list | grep image` 检测——实测对"PNG 塞进 PDF 外壳"返回 0,**漏检**。
3. **非矢量字体**:字体类型为 **Type 3** → **R4 退回**(须 TrueType / CID TrueType)。
   > 注:仅检查"是否嵌入"(emb 列)会漏判——Type 3 同样显示 emb=yes,但为期刊普遍不接受的内嵌方式。
4. **无文本层**:`pdftotext` 输出为空 → **R4 退回**。
5. **A 的目检 = 机读证据核验 + 图注与正文数字一致性核验**,**不依赖人眼观察图像内容**。
6. **判据自校验**:本条判据须以 4 类样本(合规 TrueType / 位图 / Type 3 / 无文本层)定期回归测试,检出率须 4/4。

## §9 · V2 判定结论要求(替换 P4)

> **替换提示**:替换 V2 中"禁止原则上/视情况"的表述。

**判定结论要求(修订)**
1. 每项判据须给出**明确结论**:通过 / 条件通过 / 不通过 / **判不了**。
2. **"判不了"为合法结论**,但必须附**缺口登记**:缺什么输入、需要谁提供、阻塞级、预计。
3. **禁止**:使用"原则上""视情况""一般"等模糊表述作为结论;**禁止为规避"判不了"而给出无依据的判定**。
4. **理由**:仅禁止模糊表述而不提供"判不了"出口,会诱导判定方硬判——把"框架未定义"包装成"已通过",构成纸面闭环。

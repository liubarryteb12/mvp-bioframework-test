## 1 G-A · 校准判据(T12 / T13(b))

### 条文草案

1. **统计量**:校准斜率(可选补充:校准截距、Brier、校准曲线)。
2. **必须用交叉验证的样本外预测概率**。**禁止使用训练内拟合概率**。
3. **CI 算法**:患者级 bootstrap,**B=1000**(事件数<50 时按结局分层,≥500);重采样单位 = 独立推断单位;多中心为 cluster bootstrap。
4. **bootstrap 内部**:每个重采样样本内**重新执行 CV** 再算斜率(嵌套),不得复用原 CV 结果。
5. **判据**:校准斜率 95% CI **覆盖 1** → 满足;不覆盖 → T13(b) 不满足 → **不得用于个体风险预测** → T13 整体不成立。

### 实跑

| 项 | 值(MVP 合成值) |
|---|---|
| 训练内拟合概率校准斜率 | **1.001** |
| CV 预测概率校准斜率 | **0.841**,95% CI [0.661, 0.952] |
| 判定 | **不满足** |

> **关键**:训练内斜率恒等于 1。若不写死第 2 条,B 用训练内数据算将永远合格,**该判据形同虚设**。此条优先级高于"CI 怎么算"。

## 2 G-B · DCA 量化口径(T13(c))

### 条文草案

1. **统计量**:净获益 `NB(pt)=TP/n − (FP/n)×pt/(1−pt)`,基于 **CV 预测概率**。
2. **网格**:0.01–0.99,步长 0.01(99 点)。
3. **胜出比例**:候选 NB 严格大于基线 NB 的网格点占比。
4. **判定**:预注册区间内胜出比例 **≥ 0.5** → 满足。
5. **全区间强制报告**:必须同时报告 0.01–0.99 全区间胜出比例。
6. **区间冲突**:预注册区间 ≥0.5 而全区间 <0.5 → **判"不确定" → T13(c) 不满足 → F3**。
7. **禁止**:先看曲线后选区间。

### 实跑

| 情形 | 预注册区间 0.10–0.60 | 全区间 0.01–0.99 | 冲突 |
|---|---|---|---|
| 已校准候选 | 0.980 | 0.747 | 否 |
| **未校准候选(高区过度预测)** | **0.840** | **0.485** | **是 → F3** |

> **关键**:区间冲突**可真实发生**。若只报预注册区间,0.840 会被写成"净获益优于基线"——**报告本身没撒谎,只是没报全**。第 5、6 条是唯一能捕获它的机制,不可删。

## 3 G-C · 跨指标方向一致性(T18)

### 条文草案

1. 不同指标(OR/HR/β/ΔAUC/ΔC-index)**量纲不同,不比较大小,只比较方向**。
2. **统一符号**:一律化为"暴露升高 → 结局风险升高为正"。
   - OR/HR:取 `log(OR)` 符号(>1 为正)
   - 预测增量:取 `ΔAUC` / `ΔC-index` 符号(>0 为正)
   - 连续型:取 β 符号
3. **判据**:符号全一致 → 方向一致;任一相反 → **F1 → 降为探索级**。
4. **禁止**:以数值差异大小为由判不一致。

### 实跑

`log(OR/SD)=+0.498`(正)｜`ΔAUC=+0.0397`(正)→ 一致 → 规则可执行。

## 4 G-D · 程序定义裁决(**严于 C 倾向**)

### 实跑证据(决定性)

| 变体构造方式 | OR/SD 漂移 |
|---|---|
| 改权重 / 幂变换 | **1.8%** |
| **换成员集(仅 1/3 重叠)** | **13.9%,且方向翻转**(0.923 → 1.051) |

> 同一条"程序定义敏感性",**变体怎么造决定结果**。改权重是橡皮图章;换成员集可让**效应方向翻转**。
> 因此问题不只是"冻结前后"的时间边界,而是**"变体如何构造"未被规定**——该分析可被操纵成永远合格。

### 裁决条文

1. **程序定义不是稳健性参数,是可改变结论的自由度** → **移出 T18 必做 5 项**。
2. 新增节点 **B03-A「程序/签名定义论证」**,须在 **B03 冻结前**完成并留痕:
   - 备选定义清单(≥2 个)
   - 各定义下的效应量与方向
   - 主定义**选择理由**(文献依据 / 可复现性 / 测量可行性,**不得以后续效应量大小为理由**)
   - 定义漂移幅度与方向稳定性记录
3. **变体构造规则(强制,防橡皮图章)**:备选定义必须为**成员集层面的实质变更**(换基因集版本 / 换成员阈值 / 成员重叠度 ≤2/3),**禁止仅做权重缩放或单调变换**作为唯一变体。
4. **冻结后**:程序定义属 §10.2 不变量,**禁止更改**;敏感性矩阵仅保留:归一化 / 协变量集 / 异常样本 / 合理替代模型。
5. **定义漂移 >20% 或方向翻转** → 该程序**不得作为唯一主暴露**,须在限制中显式声明。

## 7 分支 8 补跑(硬阻断三类,全拦截)

| 类 | 实跑结果(MVP 合成值) | 判据 |
|---|---|---|
| **伪重复**<br>细胞冒充患者 | 细胞级 Wilcoxon p=**6.5e-11**(n=3000 vs 3000) 宣称极显著<br>患者级 pseudobulk p=**0.407**(n=3 vs 3) | Biological unit 必须为 donor → **硬阻断** |
| **严重泄露**<br>全数据筛特征 | 泄露 AUC=**0.972** vs 训练折内 **0.837**,虚高 **+0.136**<br>(p=2000 中真信号仅 10 个) | T10 筛选须在训练折内 → **硬阻断** |
| **终点不等价**<br>跨量表合并 | MoCA 队列 OR=**2.741**｜MMSE 队列 OR=**1.195**<br>合并 OR=**1.781**(n 翻倍,CI 更窄,"更可信")<br>**I²=96.3%,异质性 p<0.0001** | 合并前须报 I² 与事件率;**I²>50% → 禁止合并主分析** |

> **终点不等价这条最隐蔽**:合并后 OR 落在两队列之间,**会被误读为"两队列一致"**,而 I²=96.3% 说明它们根本不该合并。**合并动作本身销毁了发现异质性的能力。**

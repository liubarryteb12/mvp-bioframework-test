| **T03** | 富集:来源、版本、背景集、范围、显著性 | **来源与版本写死**(基因集库/本体库/通路库,各记版本号 + 访问日期)<br>**自定义程序集**:存为 `.gmt`,记版本号 + 生成日期 + **md5**,进版本控制<br>**背景集**:过滤后保留的全部分子(**非全基因组**)<br>**基因集大小**:默认 15–500,超出范围不检验并如实报告<br>**检验范围**:全基因组 或 程序内,**必须显式声明**并据此校正<br>**显著性**:FDR < 0.05(BH,按声明范围校正) | 可复现要求 + 方法学 | 无替代。背景集用全基因组会导致短基因集系统性假阳性——这是不可接受的。不同组学(甲基化/代谢)背景集定义须在填槽时明确 |
| **T04** | 共表达网络(默认实现:WGCNA) | **power**:取 scale-free **R² ≥ 0.85** 的最小 power;**R² < 0.80 → 判不适用并报告**,不强行建网<br>**minModuleSize = 30**;**MEDissThres = 0.25**;**deepSplit = 2**<br>**样本量 < 15 → 不适用**<br>须附尺度独立性与平均连通度诊断图 | 方法学 | 若改用其他网络方法,须预注册方法、参数与诊断标准,并附等价的诊断证据 |
| **T05** | 程序评分 | **主方法**:GSVA(版本写死),`kcdf="Gaussian"` 用于 log2 尺度或芯片矩阵;`kcdf="Poisson"` **仅用于 raw counts**<br>**敏感性**:ssGSEA(`min.sz=10`, `max.sz=500`, `tau=1`)<br>**基因集 md5 与版本写死**<br>**禁止**:评分后跨数据集 z-score 标准化再比较(等于重新定义程序);确须标准化 → 作为**独立敏感性分析**单独报告 | 方法学 | 若上游已用其他评分工具且不可回溯,须声明版本与参数,并在 T18 必做项④中做工具敏感性 |
| **T06** | 关联/生存:主分析尺度、比例风险、非线性 | **主分析 = 连续暴露**(每 1 SD 增量 或 每 log2 单位,**须预注册尺度**)<br>**分类(中位数/三分位)仅作敏感性**,切点须为预注册固定值,**禁止最优切点搜索**(禁用 maximally selected rank statistics)<br>**比例风险检验**:`cox.zph`,p < 0.05 时:(a) 加时间依存项或分层,(b) 补充报告 RMST 差;不得静默忽略<br>**非线性**:限制性立方样条(3–4 knots),报告非线性检验 p | 框架条款 + 方法学 | 无替代。连续优先是硬要求:分类化损失信息,且切点选择是泄露高发区 |
| **T07** | 协变量集(**预注册,禁止事后增删**) | 按**科学问题、时间顺序、领域知识**选择,并区分三套设计:**混杂控制集 / 机制解释集 / 预测建模集**,三套须分别预注册<br>**禁止**默认"单变量显著才进多变量"<br>须报告暴露与主要协变量的**共线性诊断(VIF)**<br>整队列未测量的变量 → 标"未测量",**限制独立关联主张**,不得插补代替 | 领域知识 + 方法学 | 具体变量清单在填槽阶段确定。加入**中介变量**会掩盖总效应,须在计划中说明为何调整或为何不调整 |
| **T08** | 缺失处理 | **报告**:每变量缺失比例(分子/分母)<br>**阈值**:单变量缺失 **> 20% → 不进主模型**,改作敏感性或限制独立关联主张<br>**插补**:`mice`,`m = 20`,`pmm`(连续)/`logreg`(二分类)/`polyreg`(多分类),迭代 20 次,**种子预注册固定**<br>**插补模型变量**:分析模型全部变量 **+ 结局**(生存结局用 Nelson-Aalen 累积风险 + 事件指示)<br>**假设**:MAR,须**明文陈述**;并做 **MNAR 敏感性**(delta 调整 或 完整病例比较)<br>**整队列未测量变量**:标"未测量",禁止当零星缺失插补 | 方法学 | 完整病例分析可作敏感性并列报告,但须写明局限(尤其当缺失与结局相关时) |
| **T09** | 预测:基线、算法集、重采样、种子 | **基线模型**:预注册**领域常规基线**(如临床变量模型 / 最强单变量),**冻结**,与候选模型走同一评价流程<br>**候选算法集**:Ridge / LASSO / Elastic Net / 随机森林 / 梯度提升 / SVM(按必要性选取,**不以算法数量评价质量**)<br>**重采样**:嵌套 CV(外层 5 或 10 折,内层 5 折);**n < 100 时**用重复 5 折 × 5 次<br>**抽样单位 = 独立推断单位**(同一受试者多个样本必须同折)<br>**种子预注册固定** | 防泄露 + 方法学 | 样本量或事件数极小时(< 50 事件),外层改重复嵌套 CV 或留一法并预先注册,同时声明性能估计的不稳定性 |
| **T10** | 特征筛选与调参隔离 | 筛选(单变量过滤、LASSO 选变量、mRMR 等)与超参数调整**全部在训练折内完成**,用 pipeline/recipe 封装<br>**禁止**先全数据筛选再 CV<br>**禁止**评价数据以任何形式进入筛选 | 框架条款 + 防泄露 | 无替代。这是硬阻断项"严重泄露"的直接来源 |
| **T11** | 阈值选择规则与数据源 | 分类阈值**二选一并预注册**:(a) 训练内最大化 **Youden 指数**;或 (b) **预设领域约束**(如敏感度 ≥ 0.80 下的最大特异度)<br>**禁止**用测试集或外部集选阈值。选 (a) 时,外部集上**直接套用该固定阈值**报告性能,不再重选 | 防泄露 | 若领域约束需在分析中确定,须改为在训练折内确定并固定,外部集不再调整 |
| **T12** | 性能评价:指标、CI、重采样单位 | **二分类**:AUC(DeLong 或重采样 CI)、校准斜率与截距 + 校准曲线 + **Brier score**、阈值性能(敏感度/特异度/PPV/NPV,**各给分子/分母**)<br>**生存预测**:时间依赖 AUC 或 C-index(含 95% CI)、指定时点校准曲线、IPCW Brier score<br>**CI**:bootstrap,**B = 1000**(样本量小则 ≥ 500),**重采样单位 = 独立推断单位**;多中心时为**中心**(cluster bootstrap)<br>**所有指标必须报 n 与 events** | 框架条款 + 方法学 | 无替代。按样本而非按受试者重采 → CI 系统性过窄 → 假阳性"显著增量" |
| **T13** | **增量判据(守门条款,分析前定死,禁止事后放宽)** | **基线模型**:T09 冻结的基线模型,与候选模型走**同一评价流程**<br>**三条须同时满足才判"有增量"**:<br>(a) **判别增量**:ΔAUC ≥ **0.05**(或 ΔC-index ≥ **0.03**),**且** bootstrap 95% CI **下限 > 0**;CI 跨 0 → 判"不确定",**不判有增量**<br>(b) **校准**:校准斜率 95% CI 覆盖 1,**或** Brier 优于基线且差值 95% CI 下限 > 0;跨 0 → 判"不确定"<br>(c) **决策意义**:DCA 在预注册阈值概率区间(建议 **0.10–0.60**,填槽时按应用场景定死)内净获益**不低于**基线(允许部分区间重叠,不得全程低于)<br>**最小有意义差值**:ΔAUC = **0.05**<br>**不满足 (a) → 触发 F3 → 停止升级**,仅保留较低层级主张,**禁止**写"改善决策" | 框架条款 + 领域常规 | 无替代。判据一旦事后放宽,整条升级链失效。**它防的坑:ΔAUC = 0.012 且 CI 跨 0,却写成"显著提升预测性能"** |
| **T14** | **复现判据(守门条款,禁止事后放宽)** | **冻结对象原样套用**:候选清单、程序定义(含版本)、风险方向、暴露尺度、筛选规则、阈值**全部冻结**,新数据上**不得重新筛选、不得重新调阈**<br>(a) **方向一致**:效应符号在两数据集一致<br>(b) **区间重叠**:两个 95% CI 存在重叠区间(不要求点估计落入对方 CI)<br>(c) **异质性容忍度**:**I² ≤ 50% 且异质性检验 p ≥ 0.05**;若样本/事件数不足以支撑异质性检验 → 改判"仅方向一致",降级为**相关支持**,禁止写"复现"<br>(d) 方向一致但 (b) 或 (c) 不满足 → **"不确定(保留,不补齐)"**,定性为探索级,不进主结论<br>(e) **方向相反 → "不支持稳定泛化",触发 R5 回退**<br>(f) 重新校准或重新训练 → 必须**单独报告为"模型更新"**,不替代原模型评价 | 框架条款 + 方法学 | 无替代。**它防的坑:换个基因集版本、重新调个阈值重跑一遍,然后说"复现成功"** |
| **T15** | 单细胞 QC `[条件启动]` | **生效条件**:项目启用 B08 定位(由 B 在 S02 举证,C 确认);否则 `不适用 + 理由`<br>`min.nFeature ≥ 500 且 ≤ 6000`(上限按数据分布调整并报告);`min.nCount ≥ 1000`<br>**mito% < 15%**;**单核 RNA(snRNA-seq)→ 放宽至 < 5%** 或标 `不适用 + 理由`(核 RNA 线粒体含量本就低,照抄胞质 RNA 阈值会把目标细胞滤光)<br>**doublet**:DoubletFinder 或 scDblFinder,预期率按上样量查表<br>**归一化**:LogNormalize(`scale.factor=1e4`)或 SCTransform,**二选一并全程一致,版本写死**<br>**每样本独立 QC**,QC 前后细胞数须报告(数值走台账) | 方法学 + 数据类型特异性 | 若沿用上游已处理对象,须声明 QC 参数与版本,并回溯核查是否符合上述下限。**注意 Y12:产出含单细胞图即回溯适用** |
| **T16** | 单细胞推断层级 `[条件启动]` | **推断单位 = donor(个体),不是细胞**<br>**聚合规则**:pseudobulk 按 `donor × celltype` 聚合(sum counts 或 mean log-normalized,**二选一预注册**);每 (donor, celltype) 至少 **10 个细胞**,否则该组合不纳入;每 celltype 至少 **3 个 donor**,否则该 celltype **只作描述不作推断**<br>**差异分析**:pseudobulk 层级模型(DESeq2/limma-voom 或混合模型);**禁止**用细胞级 Wilcoxon 结果作个体级结论<br>**组成分析**(细胞比例变化)与**状态分析**(差异表达)**分开报告** | 框架条款 + 方法学 | 无替代。**它防的坑:3 个 donor 的 3000 个细胞做 Wilcoxon,得 p<1e-10 宣称"极显著"** |
| **T17** | 计算扰动 `[条件启动]` | **生效条件**:B09 启动(候选基本稳健 + 背景明确 + 模型适用性可评估 + 预测可被实验检验)<br>**扰动对象**:预注册候选清单<br>**方式**:计算敲除(降至基线分位)/ 计算过表达(升至预注册分位),**禁止直接乘以任意倍数**<br>**幅度**:以**观测分布分位数**定义(敲除 → 第 1 分位;过表达 → 第 99 分位),须报告实际变化倍数<br>**输出**:下游程序评分或指定读出集的变化<br>**基准**:与**随机基因集**(同大小,**n = 1000 次置换**)的零分布比较<br>**参数敏感性网格**:≥ 3 档幅度 × 2 种背景<br>**稳定性判据**:≥ **2/3** 参数组合下方向一致才算"稳定";否则**降级为"不稳定,不采用"**<br>**外推风险**:明文陈述"计算扰动不构成功能验证" | 框架条款 + 方法学 | 若模型不支持分位扰动,须预注册替代幅度定义并说明可比性 |
| **T18** | 敏感性矩阵必做子集 | **必做 5 项**:① 归一化或特征定义 ｜② 协变量集(全集 vs 精简集)｜③ 异常样本(留一法或影响诊断,**报告影响最大者**)｜④ 程序定义(工具或版本/成员敏感性)｜⑤ 合理替代模型<br>**按需 6 项**(B 提案 + **A 批准**后方可加):缺失处理 / 时间范围 / 亚组 / 组织纯度 / 细胞组成 / 其他<br>**铁律**:**不要求全部显著,要求完整报告 + 解释一致**。只报显著项 = 严重选择性报告(硬阻断)<br>**任一必做项方向与主分析相反 → 触发 F1 → 降为探索级** | 框架条款 + 防选择性报告 | 无替代。5 项是保底,不是上限 |

## 4 五视角评审判定卡(V1–V5)

> 用法:C 在 S09 主导逐视角过审,每视角逐条勾选;A 负责 V3/V4 的实质判定。
> 【待补·§22.3 五视角评审原文,补发后对照复核】

### V1 科学问题与增量

**必查项**
- [ ] 任务分类**唯一指定主任务**,辅助任务已列出且未越界
- [ ] 估计目标**九字段全部填写**,无留空(不适用带理由)
- [ ] **证伪条件 ≥ 3 条,写死且可判定**
- [ ] 六维增量审查完成,**对比集 ≤ 3 篇**且逐一列出(文献标识 + 差异维度),**至少两维有别**
- [ ] **无任务混用**(差异 ≠ 诊断性能;生存关联 ≠ 预测模型验证;功能实验 ≠ 临床标志物验证;分子对接 ≠ 结合/功能/疗效;单细胞定位 ≠ 独立个体结局验证;代理结局未经说明不得替代真实终点)
- [ ] Population 的**关键限定**已写死;Time origin 与 Time horizon 明确
- [ ] Biological unit **唯一且全稿一致**(含图注 n 的层级标注)(Y2)

**否决项**:问题不可证伪 ｜ 六维无差异且无其他定位 ｜ 存在任务混用且未撤销相关主张

**需要的实物证据**:研究问题卡(B01 产物)｜最接近研究对比表(≤3 篇)｜手稿 Introduction 与 Aim 段

**判定写法**:通过(全勾且无否决)｜条件通过(列补件清单与期限)｜不通过(命中否决 → 回 B01 重定义)

### V2 数据与独立性

**必查项**
- [ ] 九槽位全填,未用槽位写 `不适用 + 理由`,**无静默删除**
- [ ] 多角色数据集**每种角色独立举证独立性判据**,且未重复计数(X4)
- [ ] 每数据集:平台 / 物种与组织 / **独立推断单位 n** / 样本 n / 终点可用性 / 随访 / 独立性判据 / 许可 / 版本与访问日期 / **md5 或等价校验值** / 出处行号
- [ ] 独立性 5 项 + §6.3 六条硬性口径逐条核对
- [ ] **同一队列多 accession 已核查**(不同 accession 不自动独立)
- [ ] 定位类数据集:**有结局?无结局者不得承担结局验证**(已标注)
- [ ] 终点协调四分支已走完;**跨量表/跨定义未强行换算合并**
- [ ] **主终点定义唯一**(不同时点或不同定义未混为一个终点)
- [ ] 时间点漂移已画**时间轴**(取样 / 评估 / 随访相对位置)
- [ ] 许可与数据可用性声明齐备(accession 或受控数据审批号)(Y10)

**否决项**:独立性错误(内部评价/正交/跨物种冒充独立复现)｜终点不等价却合并并写"验证"｜无结局的定位数据承担结局验证｜身份不明且未暂停核查

**需要的实物证据**:数据角色与独立性表｜终点与变量字典(含时间轴)｜许可文件/accession 列表｜手稿 Methods 数据部分

### V3 方法与统计防错

**必查项**
- [ ] **T01–T18 全部有确定值或"不适用+理由"**,且有冻结版本号
- [ ] 变更记录 **8 字段**完整;执行后改动已标 **R3** 并降级
- [ ] 每个产物**打分析阶段标签**(五类之一),无标不验收
- [ ] 防泄露 **7 项**逐条核对(插补/标准化/特征选择/过采样/降维/**阈值选择**/超参数调整全在训练折内)
- [ ] **重采样单位 = 独立推断单位**(或中心/聚类),已写明
- [ ] **多重检验家族定义明确**(家族是什么、多少次、如何校正;主终点族与探索族分开)(Y3)
- [ ] 生存分析 **9 条**逐条核对(连续为主 / 比例风险 / 非线性 / **无最优切点** / 事件与删失 / 时间起点 / 随访 / 极端值 / 复杂度与事件数匹配)
- [ ] **竞争事件处理已预注册**(Y4)
- [ ] **协变量集为预注册,非事后增删**;三套设计(混杂/机制/预测)已分开(T07)
- [ ] **批次与分组耦合处理正确**(分层或随机效应,未当协变量回归掉/未盲用 ComBat)(Y6)
- [ ] **数据库与软件版本已锁定**(名称+版本+访问日期+md5)(Y1)
- [ ] 敏感性矩阵 **5 项必做完整报告**(含不显著者)

### 6.1 措辞纪律表(禁用 → 可直接贴进稿件的替代表述)

| 禁用 | 替代(可直接贴) | 触发条件 |

| 验证了该标志物 / 得到验证 | 该候选在独立数据集中**方向得到重复**;该候选获得独立数据集支持 | 未满足 T14 全条件时 |
| 诊断标志物 / 具有诊断价值 | 与目标状态相关的**候选标志物** | 仅有关联证据 |
| 可用于临床诊断 / 可临床转化 | 在当前设计与预注册阈值下判别表现为【待台账·L-???】,**尚需前瞻性验证** | 未完成外部评价 |
| 机制阐明 / 驱动 / 调控 | **提示**涉及某程序;**计算扰动预测**其可能参与 | 仅富集或计算扰动 |
| 显著改善临床决策 | 相对预设基线模型,增量指标为【待台账·L-???】(判据 T13);其决策意义**尚需**决策曲线与前瞻性研究支持 | 未满足 T13 三条 |
| 已证实结合 / 有效药物 / 潜在治疗药物 | **候选优先级排序结果**;待实验验证的候选化合物 | B10 输出一律 |
| 首次发现 | 在本研究检索范围内未见报道(须附**检索策略与检索日期**) | 任何"首次"类主张 |
| 结果稳健 / 所有分析均显著 | 在预注册的 5 项敏感性分析中,**M 项方向一致**(须如实给出 M) | 存在不显著敏感性项时 |
| X 导致 / 引起 Y(因果口吻) | X 与 Y 风险升高相关 | 观察性关联 |
| 独立验证(同队列多 accession / 同个体多平台) | **内部评价** 或 **内部正交支持** | 不符合 §6.3 独立性六条 |

### 6.2 证据分级 ↔ 主张上限映射表(摘要/讨论/图注分别能写到什么程度)

| 证据等级 | 达成条件 | 主张上限 | 摘要可写到 | 讨论可写到 | 图注可写到 |
|---|---|---|---|---|---|
| **候选** | 单次 discovery 支持,未独立复现 | **L1** | "在发现集中与结局相关""提示""候选" | 可提假设与局限,可与文献对照;**不得**谈泛化 | "发现集,n =【待台账】,探索性" |
| **强化** | 内部稳健性/敏感性一致,或正交层面支持 | **L1–L2** | "在多种分析选择下稳健""得到正交层面支持" | 可讨论可能的生物学含义,**须带"待独立验证"** | "敏感性分析 / 正交层面,探索性" |
| **可转化候选** | 独立数据方向 + 区间满足 **T14**,或冻结流程完成外部评价 | **L2** | "在独立数据集中方向一致""转化一致性" | 可与既有研究比较、讨论适用边界;**不得**谈临床效用 | "独立数据集,方向一致性,**非临床效用验证**" |
| **证据** | 与具体主张匹配的功能/机制(**L3**)或临床效用(**L4**)证据 | **L3 / L4** | **L3**:仅针对该具体功能主张;**L4**:仅针对该具体应用场景 | 按具体主张**严格限定** | 须标注实验类型 / 效用研究设计与 n |

**贯穿硬规则**:**图注强度 ≤ 正文强度 ≤ 摘要强度 ≤ 证据上限**。任一处超标 → R5 回退,重算受影响文本与图注。**一个功能实验不得提升全部主张。**

> 补充核定:等级是**项目内审核标签**,不是跨研究的统一线性排序。研究设计、样本量、终点客观性均会影响同一等级的实质强度——讨论中不得用"达到 L2"这类内部标签对外表述。

# S19 · T13(c) 修订条文 —— 子区间操纵空间

> 发出方 A ｜ 性质:**可落盘条文**,替换 S15-C §2
> 触发原因:四角度审核 + 交叉验证实跑发现原论证不成立,需重写

---

## 0 修订原因(如实说明)

原 T13(c) 的核心依据是"**区间冲突**":预注册区间内 ≥0.5 而全区间 <0.5 → 判不确定。

**实跑发现:该情形是窄窗口事件,不一定发生。**

| 尝试的未校准构造 | 结果 |
|---|---|
| `pf × 1.35`(原构造,被审核指出人为) | 人为放大,证据无效 |
| 误用样本内预测概率(忘记 CV) | 低维 logistic 下概率**不会**更极端;高维下反而**全区间虚假完美** |
| 高维过拟合(300 噪音特征 + 无正则) | 区分力崩塌(AUC 0.544),**处处劣于基线**,无操纵空间 |
| logit 锐化(区分力不变、校准失败) | 全区间 0.253,但**存在子区间胜出率 1.000** |

**窗口为何窄**:全区间 99 点,预注册区间占 51 点。要让总数跌破 0.5(≤49 点胜出),
需预注册区间内至少 2 点劣于基线、且极端区几乎全负——条件苛刻。

> **结论:原论证的证据基础被我自己推翻。但"全区间强制报告"这条规则本身是对的,
> 只是依据错了。以下是修正后的依据——它比原依据更强。**

## 1 真正要防的坑:子区间操纵空间

### 1.1 实跑证据(MVP 合成值)

| 模型 | 区分力 AUC | 全区间 0.01–0.99 | **最优子区间** | 落差 |
|---|---|---|---|---|
| 已校准候选 | 0.674 | 0.717 | 1.000 (0.24–0.33) | **+0.283** |
| **未校准候选**(锐化 s=2.0) | **0.674**(未变) | **0.253** | **1.000 (0.42–0.51)** | **+0.747** |

**关键事实**:
- 未校准模型在**全区间上明显劣于基线**(0.253,远不达标);
- 但**总存在一段子区间**(0.42–0.51)使其胜出率达到 **1.000**(完美达标);
- **落差 0.747** —— 且该模型的区分力(AUC)与已校准模型**完全相同**。

> **这意味着:一个在全区间上明显不合格的模型,只要挑对区间,就能报告
> "净获益 100% 优于基线"。报告本身没有撒谎,只是没报全。**

### 1.2 为什么这比"区间冲突"更值得防

| | 区间冲突 | 子区间操纵 |
|---|---|---|
| 发生条件 | 窄窗口,罕见 | **普遍存在**(任何模型都有最优子区间) |
| 已校准模型 | 不发生 | 也存在(落差 0.283) |
| 未校准模型 | 不一定 | **落差达 0.747** |
| 检出方式 | 预注册区间 vs 全区间 | **扫描全部连续子区间** |
| 危害性 | 中 | **高:可把不合格伪装成完美** |

## 2 修订条文(替换 S15-C §2)

**T13(c) 决策意义判据(修订版)**

1. 统计量:净获益 `NB(pt) = TP/n − (FP/n) × pt/(1 − pt)`,基于 **CV 预测概率**。
2. 采样网格:阈值概率 **0.01–0.99,步长 0.01**(99 点)。
3. 胜出比例:候选模型 NB 严格大于基线模型 NB 的网格点占比。
4. **全区间强制报告:必须报告 0.01–0.99 全区间胜出比例。预注册区间只决定解读重点,不决定报告范围。**
5. **子区间操纵空间检查(新增,核心)**:
   - 扫描**所有长度 ≥10 个网格点的连续子区间**,报告其中**最高胜出率**及其对应区间;
   - 计算**落差** = 最高子区间胜出率 − 全区间胜出率;
   - **落差 > 0.30 → 结论高度依赖区间选择**,须在结果中显式标注;
   - **若全区间 < 0.5 但存在子区间 ≥ 0.5 → 判"不确定" → T13(c) 不满足 → 触发 F3**。
     > 此条直接封堵"挑好看区间达标"的操纵路径。
6. **禁止**:先看 DCA 曲线后选择区间;禁止仅报告子区间结果。
7. 判定:预注册阈值概率区间内胜出比例 ≥ 0.5 → 满足(但须同时满足第 5 条)。

**依据**:实跑显示未校准模型(区分力不变、仅校准失败)可实现
全区间 0.253 而最优子区间 1.000,落差 0.747。仅凭预注册区间无法检出此类操纵。

## 3 副产品:另一个被实跑证实的陷阱

**高维过拟合 + 忘记 CV = 全区间虚假完美**

| 项 | 值 |
|---|---|
| 高维模型样本内准确率 | **1.000**(完美分离) |
| 同模型样本外 AUC | 0.544(崩塌) |
| 正常模型 CV AUC | 0.674 |

> 若用样本内预测概率做 DCA,会得到"处处完美"的曲线。
> **这不是区间冲突,而是更危险的虚假完美**——它连被怀疑的机会都没有。

**新增判据(建议并入 T09/T12)**:
- 任何用于 DCA / 校准 / 性能评估的预测概率,**必须是样本外(CV 或独立集)**;
- 报告中须声明预测概率的来源(样本内 / CV / 外部集);
- **样本内准确率 > 0.95 而样本外 AUC 显著更低 → 强制标注过拟合警示**。

> 性质:供 C 落盘 v1.8 的条文草案。每条均经合成数据实跑,**非纸面推演**。
> 所有演示数字均为 `MVP 合成值·非项目实际值`,不得进入任何稿件。

## G-A · 校准判据(T12 / T13(b))

### 条文

**T13(b) 校准判据**
1. **校准统计量**:校准斜率(calibration slope)。可选补充:校准截距、Brier、校准曲线。
2. **计算必须用交叉验证的样本外预测概率**。**禁止使用训练内拟合概率**。
3. **CI 算法**:患者级 bootstrap,**B = 1000**(事件数 < 50 时按结局分层抽样,≥ 500);**重采样单位 = 独立推断单位**;多中心时为 cluster bootstrap。
4. **bootstrap 内部**:在每个重采样样本内**重新执行 CV** 得到预测概率后再算斜率(嵌套),不得复用原 CV 结果。
5. **判据**:校准斜率 95% CI **覆盖 1** → 满足;不覆盖 → T13(b) 不满足 → **不得用于个体风险预测**,并触发 T13 整体不成立。

### 实跑结论

| 项 | 值(MVP 合成值) |
|---|---|
| 训练内拟合概率的校准斜率 | **1.001** |
| CV 预测概率的校准斜率 | **0.841**,95% CI [0.661, 0.952] |
| T13(b) 判定 | **不满足**(CI 不覆盖 1) |

> **关键**:训练内斜率恒等于 1(本例 1.001)。**若不写死第 2 条,B 用训练内数据计算将永远合格,该判据形同虚设。**此条优先级高于"CI 怎么算"。

## G-B · DCA「不低于基线」量化口径(T13(c))

### 条文

**T13(c) 决策意义判据**
1. **统计量**:净获益 `NB(pt) = TP/n − (FP/n) × pt/(1 − pt)`,基于 **CV 预测概率**。
2. **采样网格**:阈值概率 **0.01–0.99,步长 0.01**(99 点)。
3. **胜出比例**:候选模型 NB 严格大于基线模型 NB 的网格点占比。
4. **判定**:预注册阈值概率区间内**胜出比例 ≥ 0.5** → 满足。
5. **全区间强制报告**:**必须同时报告 0.01–0.99 全区间胜出比例**,预注册区间只决定解读重点,不决定报告范围。
6. **区间冲突**:预注册区间内 ≥ 0.5 而全区间 < 0.5 → **判"不确定" → T13(c) 不满足 → 触发 F3**。
7. **禁止**:先看曲线后选区间。

### 实跑结论

| 区间 | 胜出比例(MVP 合成值) |
|---|---|
| 预注册区间 0.10–0.60 | 0.720 |
| 低阈值区 0.01–0.10 | **0.300** |
| 高阈值区 0.60–0.99 | 0.821 |
| 全区间 0.01–0.99 | 0.717 |

> **关键**:低阈值区胜出仅 0.300,高阈值区 0.821 —— **区间选择会实质改变结论**。本例全区间未跌破 0.5(0.717),但稀释效应已可见:若低阈值区占比扩大,全区间即跌破而预注册区间仍达标。**第 5、6 条是防"挑一段好看区间"的核心,不可删。**

## G-C · 跨指标方向一致性(T18)

### 条文

**T18 补充:敏感性分析的跨指标方向一致性规则**
1. 不同指标(OR / HR / β / ΔAUC / ΔC-index / 程序评分差)**量纲不同,不比较大小,只比较方向**。
2. **统一符号约定**:一律化为"**暴露升高 → 结局风险升高为正**"。
   - OR / HR:取 `log(OR)` 的符号(>1 为正)。
   - 预测增量:取 `ΔAUC` 或 `ΔC-index` 的符号(>0 为正)。
   - 连续型:取回归系数 β 的符号。
3. **判据**:所有纳入比较的指标**符号一致** → 方向一致;任一符号相反 → 触发 **F1 → 降为探索级**。
4. **禁止**:以"AUC 从 0.70 到 0.71"与"OR 从 1.6 到 1.9"数值差异大为由判不一致。

### 实跑结论

`log(OR/SD) = +0.498`(正)｜`ΔAUC = +0.0397`(正)→ 符号一致 → 判**方向一致**。规则可执行。

## G-D · 程序定义 vs 不变量冲突裁决(**裁决严于 C 的倾向**)

### 实跑结论(决定性证据)

| 变体构造方式 | OR/SD 漂移 |
|---|---|
| 改权重 / 幂变换 | **1.8%** |
| 换成员集(仅 1/3 重叠) | **13.9%,且方向翻转**(0.923 → 1.051) |

> **关键**:同一条"程序定义敏感性",变体怎么造决定结果。改权重是橡皮图章(漂移 2%,永远"稳健");换成员集可让**效应方向翻转**。
> **因此问题不只是"冻结前后"的时间边界,而是"变体如何构造"未被规定 —— 该分析可被操纵成永远合格。**

### 裁决条文

1. **程序定义不是稳健性参数,是可改变结论的自由度。**
   **将"程序定义"移出 T18 必做 5 项。**
2. 新增节点 **B03-A「程序/签名定义论证」**,须在 **B03 冻结前**完成并留痕,内容包括:
   - 备选定义清单(≥ 2 个);
   - 各定义下的效应量与方向;
   - 主定义的**选择理由**(文献依据 / 可复现性 / 测量可行性,**不得以后续效应量大小为理由**);
   - 定义漂移幅度与方向稳定性记录。
3. **变体构造规则(强制,防橡皮图章)**:备选定义必须为**成员集层面的实质变更**(如换基因集版本、换成员阈值、成员重叠度 ≤ 2/3),**禁止仅做权重缩放或单调变换**作为唯一变体。
4. **冻结后**:程序定义属 §10.2 不变量,**禁止更改**;敏感性矩阵仅保留冻结后仍允许项:归一化 / 协变量集 / 异常样本 / 合理替代模型。
5. **定义漂移 > 20% 或方向翻转** → 该程序**不得作为唯一主暴露**,须在限制中显式声明。

## G-E · 种子稳健性(T09 / 复算包)

### 条文

**T09 补充 + 复算包要求**
1. 主结果种子**预注册固定**,写入复算包。
2. **追加报告「种子稳健性」**:至少 **3 个额外种子**(与主种子不同)重跑主分析,报告:
   - 各种子下的效应量点估计与区间;
   - **结论方向是否一致**(首要素);
   - 点估计极差。
3. **判据**:结论方向全部一致 → 稳健;**任一种子方向翻转 → 触发 F1 → 降为探索级**。
4. **点估计极差 > 主效应量的 10%** → 必须**显式报告极差**,并禁止在摘要中只呈现单一种子的点估计。
5. 与 T07「换种子 = R3」不冲突:**主结果仍以预注册种子为准**,额外种子仅作稳健性报告,**不得挑选"最好看"的种子替换主结果**。

### 实跑结论

| 种子 | OR/SD | AUC |
|---|---|---|
| 20260910(主) | 1.645 | 0.698 |
| 20260101 | 1.802 | 0.694 |
| 20260315 | 1.484 | 0.662 |
| 20260707 | 1.639 | 0.736 |

结论方向全部一致(OR > 1);**点估计极差 0.319(约 20% > 10% 阈值)** → **须显式报告**。
> **关键**:只报主种子会制造"OR = 1.645"的精度幻觉,实际换种子即 1.48–1.80。

## G-F · 交付层与目检可判性(§16.5 / M11–M18)

### 实跑结论:目检可判,但**必须靠机读证据,不能靠人眼看图**

已产出矢量 PDF 并通过全部机读核验:

| 项 | 命令 | 结果 |
|---|---|---|
| 矢量性(非位图) | `pdfinfo -list \| grep -c image` | **0 → 真矢量** |
| 字体嵌入 | `pdffonts` | `WenQuanYiMicroHei (Custom)` 已嵌入 |
| 文本层可检索 | `pdftotext` | 可提取中英文 |
| 页面尺寸 | `pdfinfo` | 249.66 × 158.30 pt(≈88×56 mm,合单栏) |
| 体积 | `du -h` | 44 K(≤ 10 MB) |

### 条文(修订 M11–M18 的判定方式)

1. **目检级判定接受机读证据**。B 必须提交以下**命令原始输出**(非文字转述):
   `pdffonts`(字体嵌入列表)、`pdfinfo`(页数/尺寸/加密)、`pdfinfo -list`(图像对象计数)、`pdftotext`(文本层抽样)、`sha256sum`、文件字节数。
2. **位图冒充矢量**判据:`pdfinfo -list` 中图像对象数 **> 0** 且未声明为必需的栅格底图 → **R4 退回**。
3. **无文本层**判据:`pdftotext` 输出为空 → **R4 退回**。
4. **A 的目检 = 机读证据核验 + 图注与正文数字一致性核验**,**不依赖人眼观察图像内容**。
   —— 此条解决"A 无法访问文件因而目检权与验证能力脱节"的结构性问题。

## 标题
无泄露转录组风险评分对肺腺癌复发的预后增量价值

## 摘要
在 GSE31210 队列（n = 204）中，训练折内特征选择构建的转录组风险评分对肺腺癌术后复发显示预后增量：交叉验证 AUC 0.832，较临床基线（年龄、性别、分期）提升 ΔAUC = 0.167（95% CI 0.071–0.276）[L-003]。背景：基于公共表达谱的复发分层多依赖全队列特征选择，其效能估计存在选择泄露导致的虚高风险，临床增量在多数报道中未被量化 [1] [2]。方法：从 GEO 获取 GSE31210 系列矩阵（GPL570 平台，246 例样本），肿瘤与癌旁行 Welch 双侧 t 检验结合 BH 校正筛选差异表达探针；在五折交叉验证的训练折内完成生存初筛（log-rank，FDR < 0.1）与特征选择（初筛显著探针按 χ² 取前 200），以 L2 正则 logistic 回归输出折外风险评分；Cox 比例风险模型与 Kaplan-Meier 估计评价无复发生存分层，500 次 bootstrap 给出 ΔAUC 区间 [4] [5] [6]。结果：共检出差异表达探针 10275（上调 4646，下调 5629）[L-001]；风险评分高分组的无复发生存劣于低分组（log-rank P = 4.9e-10）[L-006]，评分每升高一个标准差，复发风险比 HR = 1.589（95% CI 1.399–1.804）[L-005]；全队列选择（模仿既有 GEO 队列研究的做法）使表观 AUC 由 0.832 抬升至 0.994，虚高 +0.163 [L-010]。结论：在不使用结局信息出折的前提下，转录组风险评分对肺腺癌复发具有可量化的预后增量 [L-003]，特征选择协议是既有报道效能差异的重要来源 [L-010]；局限在于该增量来自单一回顾性公共队列，未经前瞻验证，外推以 n = 204 的训练口径为界。

## 引言
肺癌是全球疾病负担最重的恶性肿瘤之一，肺腺癌是非小细胞肺癌中最常见的组织学类型 [8]。基于表达谱的复发分层已有多个报道：Shedden 等以多中心盲法验证了表达数据对肺腺癌生存的预测力 [2]，Beer 等更早构建了预后表达模型 [3]。这类研究多从 GEO 公共队列出发，经差异表达、通路解释与基因签名三步产出风险评分 [1]。既有报道普遍在全队列上完成特征选择与效能估计，选择阶段使用结局信息会使交叉验证之外的效能估计偏高，该风险在方法学上已被指出，同批数据上的定量对照目前缺乏。本研究以 GSE31210 队列为对象做三件事：在预注册阈值与折内选择约束下复现 GEO 队列预后研究的方法链；量化风险评分相对临床基线的预后增量；在同一批数据上给出特征选择协议对效能估计影响的定量对照。

## 方法
数据与治理：从 GEO 下载 GSE31210 系列矩阵（登录号 GSE31210，GPL570 平台，246 例样本：226 例原发肿瘤、20 例癌旁），强度值取 log2(x+1)。元数据含组织类型、年龄、性别、病理分期（IA/IB/II）、复发状态与随访天数；按元数据既定排除标记（不完全切除或辅助治疗）剔除 22 例，预后分析集 n = 204、复发事件 54 [L-008]。技术批次：单一数据集、系列矩阵不含扫描批次字段，不作批次校正处理。本研究仅使用 GEO 已公开的去标识化数据，不涉及新增人类受试者，无需伦理委员会审批。

差异表达：肿瘤 vs 癌旁，Welch 双侧 t 检验，BH 多重校正 [4]，阈值 |log2FC| ≥ 0.585 且 P.adj < 0.05。通路富集：上调与下调差异基因分别提交 Enrichr（GO Biological Process 与 KEGG），P.adj < 0.05 记为富集。

风险评分构建（预注册与偏差声明）：阈值与流程在分析前预注册；初版以 |log2FC| 排序选取特征，真数据实跑无信号（AUC 0.532）后修订为训练折内 log-rank χ² 排序，修订与对照实验完整记录于分析档案，未因结果调整阈值。五折分层交叉验证（种子 20260910）内完成生存初筛（中位分割 log-rank，FDR < 0.1）与特征选择（显著探针按 χ² 取前 200），L2 正则 logistic（C = 0.1）输出折外预测 [L-004]；结局信息不出训练折。

统计：Cox 比例风险模型（Breslow）估计评分与复发的关联 [5]，Kaplan-Meier 估计生存曲线 [6]，中位分割行 log-rank 双侧检验；临床增量以基线模型（年龄、性别、分期）与基线加评分模型的折外 AUC 差（ΔAUC）及 500 次 bootstrap 区间报告。样本量与效能：预后集 n = 204、事件 54，单评分变量 EPV = 54 ≥ 10 [L-009]。报告口径遵循 TRIPOD 声明并附逐条对照表 [7]。软件：Python 3.14（numpy 2.5.0 / scipy 1.18.1 / scikit-learn 1.9.1 / statsmodels 0.15.0），分析代码与台账随分析档案交付。

## 结果
分析流程：预注册阈值 → 差异表达 → 通路富集 → 训练折内生存初筛与特征选择 → 风险评分 → 效能与增量评估 → 协议对照与亚组稳健性，全链在固定种子（20260910）下一次跑通。

队列特征：246 例样本中，肿瘤 226 例、癌旁 20 例；按既定排除标记剔除 22 例后，预后分析纳入 204 例、复发事件 54 例 [L-008]。分期构成 IA 109 例、IB 53 例、II 42 例；女性 109 例、男性 95 例。肿瘤与癌旁的强度分布在 log2 转换后量级一致，无整体偏移。

差异表达：肿瘤与癌旁间共检出差异表达探针 10275，上调 4646、下调 5629 [L-001]（图 1）。

通路富集：上调探针集中于胞外结构组织与有丝分裂纺锤体检查点相关通路，下调探针集中于血管生成调节等通路；显著通路上调 18 条、下调 418 条（P.adj < 0.05）[L-002]（图 2）。

风险评分与生存分层：每折在 10275 个差异探针内完成生存初筛，平均 3734 个探针通过 FDR < 0.1，无折回退 [L-004]。折外风险评分中位分割后，高分组（n = 102）的无复发生存劣于低分组（n = 102），log-rank χ² = 38.74，P = 4.9e-10 [L-006]（图 3）；评分连续入模，HR = 1.589（95% CI 1.399–1.804），P = 1.0e-12 [L-005]。

预测效能与临床增量：五折折外 AUC = 0.832；基线模型（年龄、性别、分期）AUC = 0.664，加入评分后 ΔAUC = 0.167（95% CI 0.071–0.276），区间下限大于 0 [L-003]（图 4）。

特征选择协议的对照：在同批数据上，全队列初筛加全队列拟合（模仿既有 GEO 队列研究的做法）给出表观 AUC = 0.994（top200）与 0.934（top50），较折内协议的 0.832 与 0.824 分别虚高 0.163 与 0.110 [L-010]。该对照仅用于量化选择泄露的影响，不构成效能主张。

亚组稳健性：评分的风险方向在分期 IA（HR = 1.858）、IB（HR = 1.520）、II（HR = 1.138）亚组及男性（HR = 1.813）、女性（HR = 1.418）亚组中方向一致（均风险↑）[L-007]。未见方向翻转的亚组；分期 II 亚组样本量有限（n = 42），其中未见可解释的异质性来源。阴性事项如实登记：总生存（OS）终点未纳入本轮预注册范围，决策曲线未做，两项均不计入效能主张。

## 讨论
在 GSE31210 队列（n = 204）中，训练折内特征选择构建的转录组风险评分对肺腺癌术后复发显示预后增量：交叉验证 AUC 0.832，较临床基线（年龄、性别、分期）提升 ΔAUC = 0.167（95% CI 0.071–0.276）[L-003]。这一增量在分期与性别亚组内方向一致 [L-007]，与多中心盲法研究中表达数据可预测肺腺癌生存的方向相符 [2]，与更早的预后表达模型结论相容 [3]。

同批数据的协议对照给出本文的主要方法学观察：全队列选择使表观 AUC 由 0.832 抬升至 0.994 [L-010]。既有 GEO 队列预后报道多在全队列上完成基因筛选与效能估计 [1]，本对照在同一数据、同一模型下将虚高定量为 0.11–0.16；对读者而言，文献间效能差异的一部分可能来自选择协议而非生物学差异。

就潜在用途而言，在年龄、性别、分期之外，评分提供可量化的分层增量 [L-003]；高分组的无复发生存与低分组明确分离 [L-006]，支持其作为肺腺癌术后复发风险分层的候选工具。按证据分级，该主张限于回顾性单队列口径：它说明的是"在既有临床变量之上加入评分可改善判别"，不是"改变治疗决策"，后者需要前瞻验证与临床效用分析 [7]。

局限：单一公共队列、单一平台（GPL570），未纳入外部独立队列，效能估计未做时间依赖 ROC 与决策曲线 [7]；评分特征为探针级线性组合，基因层面解释需谨慎；候选阈值沿用预注册基线，未在更大样本上重校准。展望：在独立队列（如 GSE68465 等肺腺癌队列）上复现折内协议并报告增量，补齐决策曲线与校准评估 [7]，再考虑前瞻性验证。

## 缩写
TRIPOD：个体预后或诊断多变量预测模型透明报告声明（Transparent Reporting of a Multivariable Prediction Model for Individual Prognosis Or Diagnosis）
GEO：基因表达综合数据库（Gene Expression Omnibus）
LUAD：肺腺癌（lung adenocarcinoma）
RFS：无复发生存（recurrence-free survival）
AUC：受试者工作特征曲线下面积（area under the receiver operating characteristic curve）
ΔAUC：AUC 相对于临床基线模型的增量
ROC：受试者工作特征（receiver operating characteristic）
HR：风险比（hazard ratio）
CI：置信区间（confidence interval）
BH：Benjamini–Hochberg 法（用于错误发现率校正）
FDR：错误发现率（false discovery rate）
EPV：每变量事件数（events per variable）
